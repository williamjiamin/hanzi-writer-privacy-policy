Privacy Policy for Hanzi Writer Extension

Last Updated: 2026.1.16

Data Collection:
This extension collects minimal data that is stored locally on your device:
- Selected text from web pages (only when you use the right-click context menu)
- Your last practiced characters (for convenience)

Data Storage:
All data is stored locally using Chrome's storage.local API. No data is transmitted to external servers.

Data Usage:
- Selected text is only used to populate the practice interface
- Last practiced characters are saved to improve user experience
- No data is shared, sold, or transmitted to third parties

External Services:
The extension loads Chinese character stroke data from cdn.jsdelivr.net (a public CDN) to display character animations. No user data is sent to this service.
