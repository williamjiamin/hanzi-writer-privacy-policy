# Privacy Policy for Hanzi Writer Extension

**Last Updated: January 16, 2026**

## Data Collection

This extension collects minimal data that is stored locally on your device:
- **Selected text from web pages**: Only when you use the right-click context menu feature to practice Chinese characters
- **Last practiced characters**: Saved locally for convenience to improve your user experience

## Data Storage

All data is stored locally on your device using Chrome's `storage.local` API. **No data is transmitted to external servers or third parties.**

## Data Usage

- Selected text is only used to populate the practice interface when you use the context menu feature
- Last practiced characters are saved locally to remember your recent practice sessions
- **No data is shared, sold, or transmitted to third parties**
- **No data is used for purposes unrelated to the extension's single purpose**

## External Services

**This extension does NOT use any external services or make network requests.**

- All JavaScript code is bundled locally within the extension
- All Chinese character stroke data (9,575+ character files) is bundled locally within the extension package
- **No data is sent to external servers**
- **No remote code is executed**
- The extension works completely offline after installation

## Permissions

This extension uses the following permissions:
- **contextMenus**: To add a right-click menu option for practicing selected Chinese text
- **storage**: To save your selected text and last practiced characters locally
- **activeTab**: To open the extension popup interface

## User Rights

You have full control over your data:
- All data is stored locally on your device
- You can clear extension data at any time through Chrome's extension settings
- No personal information is collected or required

## Changes to This Policy

We may update this privacy policy from time to time. The "Last Updated" date at the top of this policy indicates when it was last revised.
